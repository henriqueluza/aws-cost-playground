- `tsconfig.json`: `tooling` no `include` e `allowImportingTsExtensions` (o Vite carrega o config sem resolver import sem extensão).

## Decisões tomadas sem humano

1. **Licença emitida do pacote no build** (não copiada para `public/fonts/`): sem duplicar texto, sempre a licença da versão instalada. Alternativa: copiar para `public/`.
2. **Um arquivo de licença por família**, pois o copyright difere (2019 Sans, 2017 Mono).
3. **Sem `preload`** das fontes: os nomes têm hash e o Vite não injeta preload de fonte; `swap` com fallback de sistema basta para o escopo. Revisar se o CLS incomodar.
4. **Guarda só olha texto** (chunk, html, css, js): woff2 é binário e não pode conter URI.
5. **Mono sem grego/cirílico**: só latin e latin-ext, como o DESIGN pede.
6. **Design (modo degradado):** a Issue só carrega fontes já definidas no DESIGN.md; sem tela nova. Sem navegador para conferir a renderização; a conferência é pelo build e pelos testes.
