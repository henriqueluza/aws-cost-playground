## Como usar (#12 e #43)

```tsx
const state = usePriceCatalog(design); // design: { region, blocks }
if (state.status === "ready") {
  const cost = estimate(design, state.catalog);
  // aviso: state.source === 'seed' e state.generatedAt
}
```

- **#12 (editor):** desenhar o aviso da origem dos preços com `source` e `generatedAt` (formate a data; não a renderize como HTML). Não precisa criar provider.
- **#43 (painel):** chamar `estimate(design, state.catalog)` em `ready`; tratar `idle` (design vazio: total zero, sem catálogo), `loading` e `error` (texto próprio por `error.kind` e botão que chama `retry`; nunca mostrar `error.message`). Com `updating: true` o catálogo é o do design anterior: o motor já marca `unavailable` o bloco sem preço e todos os blocos se a região for outra, então dá para manter os números anteriores esmaecidos ou mostrar carregando.
- O `PriceCatalog` tem `Decimal` (`bigint`): não o ponha em store persistido, em query key nem em JSON.

## Decisões

| Decisão                                                                   | Alternativa descartada                     | Motivo                                                                                                                                                                                                             |
| ------------------------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Hook em `features/pricing/hooks/`                                         | `pricing/ui/`                              | O ADR-0001 define `ui/ → hooks/ → application/ → model/`; `ui/` fica para componentes.                                                                                                                             |
| A lista de serviços inclui o `service` declarado pelas cobranças do bloco | Só o tipo sem `aws.`                       | O motor aceita `BlockCharge.service`; sem isso, um bloco que cobra SKU de outro serviço sairia `unavailable`. Hoje as funções de preço são provisórias (sem cobranças), então a lista é o tipo sem `aws.`.         |
| Bloco nível C (`iam`, `cloudformation`, `ecs`) também entra na lista      | Filtrar por nível                          | O carregador ignora serviço que o manifest não lista, sem requisição. Menos regra.                                                                                                                                 |
| `blockService` exportado de `model/engine.ts`                             | Repetir o `slice('aws.')`                  | Uma só regra para o motor e para a carga.                                                                                                                                                                          |
| Uma query por (região, lista de serviços)                                 | Uma query por serviço (`useQueries`)       | É a forma do `CatalogLoader.load` e do plano da Issue. Custo: acrescentar um tipo de bloco novo rebusca os arquivos já carregados (o adaptador usa `cache: 'no-cache'`, então é uma revalidação HTTP por arquivo). |
| `placeholderData: keepPreviousData` e o campo `updating`                  | Voltar a `loading` a cada mudança de lista | O painel não pisca a cada bloco novo; o motor já é seguro com catálogo incompleto ou de outra região.                                                                                                              |
| `staleTime` 24 h, `gcTime` 1 h, sem refetch em foco nem em reconexão      | `staleTime: Infinity`                      | O catálogo muda no máximo uma vez por semana; uma aba aberta por dias ainda revalida.                                                                                                                              |
| `retry` só para `network`, 2 tentativas a mais                            | Padrão (3, para qualquer erro)             | `missing`, `invalid`, `too-large` e `integrity` não mudam ao repetir.                                                                                                                                              |
| Erro `integrity` relê o manifest uma vez (`createCatalogSession`)         | Manifest fixo até recarregar a página      | Com o manifest em memória, um catálogo publicado de novo com a aba aberta daria `integrity` para sempre, e `retry` não resolveria. A segunda falha sai como erro: o hash continua obrigatório.                     |
| `structuralSharing: false`                                                | Padrão                                     | O dado tem `Map` e `bigint`; nada a comparar estruturalmente.                                                                                                                                                      |
| `throwOnError: false` fixo no hook                                        | Herdar do `QueryClient`                    | Critério "sem lançar na renderização", mesmo se o cliente global mudar.                                                                                                                                            |
| Segundo parâmetro `load` no hook                                          | Sessão só de módulo                        | Os testes usam uma sessão nova por caso (o manifest fica em memória).                                                                                                                                              |
| `networkMode` padrão (`online`)                                           | `always`                                   | Sem rede a query fica em `loading` e retoma sozinha ao reconectar.                                                                                                                                                 |

Patterns: nenhum novo além da porta e do adaptador já existentes; `createCatalogSession` é uma fábrica com estado (closure), pelo motivo da linha do `integrity`.
