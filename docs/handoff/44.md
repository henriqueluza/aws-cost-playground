## Decisões tomadas sem humano

- **Ícones.** O DESIGN.md manda Lucide, mas `lucide-react` não é dependência. Seis SVGs próprios no estilo dele (cpu, database, network, shield, activity, globe), sem ícone oficial da AWS. Trocar pelo pacote quando ele entrar.
- **CSS do React Flow.** `@xyflow/react/dist/base.css` entra pelo bundle (import no `CanvasPanel`). Não tem URI `data:` (conferido), então o guarda do build não foi tocado. As variáveis `--xy-*` apontam para os tokens.
- **Categorias.** contrato → desenho: compute→Computação; storage, database, integration→Dados; networking→Rede; security→Segurança; management, devtools→Operação (a tabela do DESIGN.md).
- **Layout padrão.** O design carregado não traz posição; sem layout, `defaultLayout` (esquerda para direita). Ao carregar sem layout o canvas reajusta o zoom.
- **`client` arrastável.** `moveBlock` aceita `client`; só não é removível nem selecionável (a store só seleciona bloco ou aresta).
- **Nome acessível do nó:** `Serviço, rótulo, categoria, custo por mês` no `aria-label`; texto do rótulo sempre filho React.
- **Seleção única.** Seleção múltipla desligada na parte 2 (a store guarda uma só).
- **Zoom por botões** próprios (o Controls do React Flow tem rótulos em inglês), na parte 2.
- **Passo do teclado.** Snap de 8 px; o DESIGN.md pede 8 (e 40 com Shift) e o React Flow dá 4x: ajuste na #45.
- **Bundle.** O build avisa de chunk > 500 kB com o React Flow; code-split do editor fica para depois.
