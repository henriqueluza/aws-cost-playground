## Decisões

| Decisão                                                                             | Alternativa descartada                   | Motivo                                                                                                                                                                         |
| ----------------------------------------------------------------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Porta `ReadPriceFile` devolve bytes; hash, JSON e zod ficam na aplicação            | Adaptador devolve o objeto já validado   | O hash é sobre os bytes exatos do arquivo. Com a validação na camada pura, ela é testada sem rede e o adaptador (#173) fica só com HTTP.                                       |
| `crypto.subtle.digest` chamado direto em `application/`                             | Injetar a função de hash por outra porta | Web Crypto é API padrão do navegador e do Node, sem rede nem React; o lint de pureza continua valendo. Uma segunda porta só para o hash seria abstração sem problema presente. |
| Hash conferido antes do parse                                                       | Parse primeiro                           | Conteúdo que não é o do manifest não chega ao `JSON.parse` nem ao zod.                                                                                                         |
| Serviço pedido que o manifest não lista fica fora de `services`, sem erro           | Lançar `missing`                         | O motor já tem o estado `unavailable` (handoff da #115) e o painel mostra o resto do design. Um catálogo seed parcial continua utilizável.                                     |
| Arquivo listado que falha (ausente, hash, schema) derruba a carga inteira           | Catálogo parcial                         | Falha fechada: arquivo listado e quebrado é erro de publicação ou adulteração, e não deve virar uma estimativa silenciosamente incompleta.                                     |
| `CatalogError` sem `cause` nas falhas de parse                                      | Guardar o `SyntaxError`/`ZodError`       | A mensagem do `SyntaxError` do V8 traz um trecho do arquivo; quem logasse o erro ecoaria conteúdo não confiável.                                                               |
| O manifest fica em memória por carregador; falha não é guardada                     | Reler a cada `load`; guardar a falha     | Critério "lido uma vez". Sem guardar a falha, uma nova tentativa (do TanStack Query, na #174) funciona.                                                                        |
| Os `kind` `network`, `missing` e `too-large` já existem, embora só a porta os lance | Acrescentar na #173                      | Fazem parte do contrato da porta que este PR define; o teste usa `missing` e `network` pela porta em memória.                                                                  |

Patterns introduzidos: porta e adaptador (`ReadPriceFile`), porque `application/` não pode importar `fetch` (ADR-0001) e precisa ser testada sem rede.
