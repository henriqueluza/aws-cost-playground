## Decisões

- **`REGIONAL`, `TLS_1_2` e `disable_execute_api_endpoint = true` são literais.** São os únicos valores que a HTTP API aceita nos dois primeiros, e uma variável no terceiro reabriria o contorno que a Issue fecha.
- **O mapping usa `aws_apigatewayv2_stage.default.name` e `aws_apigatewayv2_domain_name.this.domain_name`**, não os `.id`. Os dois são conhecidos no `plan` e mantêm a dependência; no provider, o id de cada um é o próprio nome.
- **`domain_alias` sai só do recurso de domínio.** O registro no Route 53 continua no módulo `dns`.
- Nenhum pattern introduzido.

## Decisões tomadas sem humano

1. **Sem `prevent_destroy` no domínio.** Não guarda dado nem identidade (critério do ADR) e se recria do código; é o mesmo precedente dos certificados e registros do `dns`. Trocar `domain_name` gera `replace` e cai no plan-guard; trocar o certificado é in-place.
2. **Fixture `tests/consumer` com `source` para o módulo irmão `dns`.** É o primeiro `source` entre módulos irmãos do repositório, só dentro de `tests/`. O critério "sem ciclo com o `dns`" só se prova com o `dns` real. Controle negativo: com um `depends_on = [aws_route53_record.api]` no output `domain_names` de uma cópia do `dns`, o run falha com `Error: Cycle`.
3. **Fixture sem `required_providers`.** A raiz dela só tem dois `module`; declarar o provider acionaria `terraform_unused_required_providers` no tflint. Por isso o run leva `providers = { aws = aws }`, para o provider simulado valer na fixture.
4. **Sem `nullable = false`.** Mantém as variáveis iguais às do `site`; `null` já é rejeitado pela validação, e há um run que prova isso.
5. **Sem `ip_address_type`, mTLS, `api_mapping_key` nem tags no domínio.** O padrão é IPv4 e o `dns` só cria registro A; as tags vêm de `default_tags` nos ambientes.
6. **Override da API nos testes ganhou `id = "api123"`.** Sem ele, o assert de `api_id` do mapping compararia um valor desconhecido consigo mesmo.
7. **Nome da branch.** O hook da fábrica bloqueia `git push.*main`, e `domain` contém `main`: a branch `issue-132-http-api-domain` não podia ser enviada. O nome `issue-132-http-api-dominio` já existia só localmente, sem commits próprios (resto de uma sessão anterior); não mexi nele e usei `issue-132-http-api-dominio-proprio`.
8. **Lockfile do módulo fora do versionamento.** O commit de resgate do supervisor (`44b0a83`) recolocou `infra/modules/http-api/.terraform.lock.hcl` (26 linhas), o que levava a medida a 164 linhas (`size:m`) numa Issue `size:s`. Saiu de novo; os módulos não versionam lockfile (`infra/README.md`). Para quem retomar: o mesmo hook do item 7 casa com a linha de comando inteira, então um push seguido de qualquer texto com `main` (até `origin/main` em outro comando da mesma chamada) é barrado. Rode o push sozinho.
9. **`infra/modules/dns/README.md` ganhou uma frase** apontando a saída `domain_alias`. É documentação do contrato entre os dois módulos, sem mudança de código no `dns`.
