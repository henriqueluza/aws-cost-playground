## Decisões

| Decisão                                                                                                           | Alternativa descartada            | Motivo                                                                                                                                                                                                                               |
| ----------------------------------------------------------------------------------------------------------------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| String decimal `^\d{1,15}(\.\d{1,12})?$`, conferida antes de `decimal()`                                          | Deixar `decimal()` validar        | `decimal()` arredonda além de 12 casas e aceita expoente e sinal; a Issue pede recusa. Preço e quantidade nunca são negativos, então o sinal também é recusado. 15 dígitos inteiros cobrem o teto de uso do design (1e12) com folga. |
| A última faixa é obrigatoriamente aberta (`upTo: null`)                                                           | Aceitar a última com teto         | Toda quantidade precisa cair em uma faixa; com teto na última, o motor teria de inventar um preço acima dele.                                                                                                                        |
| `upTo` estritamente crescente e maior que zero                                                                    | Aceitar limites repetidos         | Faixa de largura zero é erro de geração do arquivo.                                                                                                                                                                                  |
| `manifest.files` é uma lista de `{ path, sha256 }`                                                                | Objeto `{ "<path>": "<sha256>" }` | Sem chave vinda do arquivo, nenhum erro do zod carrega conteúdo arbitrário no `path` do issue, e não há chave como `constructor` para tratar. Caminho repetido é recusado.                                                           |
| `prices` é uma lista com SKU único                                                                                | Objeto indexado por SKU           | Mesmo motivo; a ordem do arquivo é preservada.                                                                                                                                                                                       |
| Leitura tolerante (chave desconhecida é descartada)                                                               | `strictObject`                    | Mesma regra do documento do design: um build anterior ainda lê um arquivo gerado por um pipeline mais novo (rollback). "Chaves por allowlist" fica atendido porque só as chaves do schema passam para a saída.                       |
| `PriceCatalog.services` é um `ReadonlyMap<string, PriceFile>`                                                     | `Record`                          | `Map` não tem chaves herdadas do protótipo.                                                                                                                                                                                          |
| `PriceCatalog` é só um tipo                                                                                       | Função `buildPriceCatalog`        | Quem monta é a carga por HTTP, fora do escopo; o motor (#115) só precisa do tipo.                                                                                                                                                    |
| Tudo em `model/catalog.ts`                                                                                        | Schema em `pricing/api/`          | A Issue permite os dois; o zod é TypeScript puro e não há ainda camada `api/` na feature. Quem fizer a carga pode mover sem mudar o `index.ts`.                                                                                      |
| Limites: 200 preços por arquivo, 16 faixas, 100 arquivos no manifest, descrição de 200 e unidade de 40 caracteres | Sem limite                        | Entrada não confiável; os números têm folga para os 20 blocos em duas regiões.                                                                                                                                                       |

## Observações do QA (sem ação neste PR)

- Quando um decimal inválido e uma faixa fora de ordem aparecem no mesmo preço, o `superRefine` roda com o valor ainda cru e o `path` do issue de faixa pode sair com índice repetido. O arquivo é recusado do mesmo jeito; importa só se a tela for mapear erro por campo.
- `description` e `unit` aceitam qualquer caractere dentro do limite de tamanho. São dados, exibidos pelo React com escape; nunca use `dangerouslySetInnerHTML` com eles.
- A unicidade de SKU diferencia maiúsculas de minúsculas.
