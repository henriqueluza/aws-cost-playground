# Handoff — Issue #242: zip das Lambdas inclui `contracts/`

## Estado

Pronto para revisão. `scripts/build-functions.sh` copia `contracts/blocks.json` e `contracts/edges.json`, por nome, para `contracts/` na raiz do pacote, ao lado de `app/`, onde `api/app/contracts.py` procura primeiro. Exemplos e cenários ficam fora. Arquivo ausente derruba o build (`set -e`).

- Conteúdo do zip (build real, 5.687 arquivos): `app/`, `contracts/` (2 arquivos), as dependências de runtime do `uv.lock` com seus `*.dist-info`, e o `.lock` vazio que o `uv pip install --target` cria.
- Determinístico: dois builds reais deram o mesmo sha256. Os dois arquivos novos passam pelo mesmo `touch` de data fixa e pela mesma ordenação.
- `.github/workflows/deploy-staging.yml` não mudou: usa o zip inteiro e o hash dele, sem lista de arquivos.

## Teste

`api/tests/test_package.py` roda o script em bash com um `uv` falso no PATH (sem rede e sem AWS) e confere: só os dois arquivos em `contracts/`, bytes iguais aos do repositório; nada de `tests`, `__pycache__`, `.pyc`, `bin`, `.env`, `examples` ou `scenarios`; dois builds com bytes iguais e o sha256 impresso; e, num subprocesso com o pacote extraído como diretório de trabalho, `app.contracts` vindo do pacote, `contracts/` do pacote como único diretório encontrado e os 20 blocos carregados.
