## Decisões tomadas (incluindo as sem humano)

| Decisão | Alternativa descartada | Motivo |
|---|---|---|
| Adapter Mangum | AWS Lambda Web Adapter | O Mangum é Python puro, fica no `uv.lock` com hash e entra na auditoria. Ele ainda exigiria um servidor (uvicorn) e mandaria o contexto do authorizer num cabeçalho (`x-amzn-request-context`), e a regra da casa é não ler identidade de cabeçalho. ## Passo do `validate` para a `api/` (aplicação humana)

Entra depois do passo do `web/` em `.github/workflows/validate.yml`. A parte 3 acrescenta `pricing/uv.lock` ao `cache-dependency-glob` e o passo do `pricing/`.

```yaml
      - uses: astral-sh/setup-uv@68559e99cc807c1eb7e9238fd43a15bba460eec2 # v10.3.3
        with:
          version: "0.13.8"
          enable-cache: true
          cache-dependency-glob: api/uv.lock
      - name: API — format, lint, tipos, arquitetura e testes
        working-directory: api
        env:
          UV_LOCKED: "1" # todo `uv run` também falha se o lock estiver desatualizado
        run: |
          uv sync --locked
          uv run ruff format --check .
          uv run ruff check .
          uv run mypy app
          uv run lint-imports
          uv run pytest -q --cov
```

O uv instala o Python 3.14 a partir de `api/.python-version`.
